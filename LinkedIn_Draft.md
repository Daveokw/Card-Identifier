I recently built a Card Identifier app that uses deep learning to recognise standard playing cards from an image. 

The goal was to get hands-on with image classification and model deployment. I fine-tuned a ResNet18 model using PyTorch and built a simple web interface with Streamlit so anyone can test it out. It handles 53 classes (a full deck plus the Joker).

It's very much a prototype right now, so the model isn't perfect. It can occasionally struggle with bad lighting or weird angles, but it's a solid proof of concept. I'm open to feedback and any suggestions for future adjustments!
